## 2. 사용자 흐름
```plain text
랜딩
→ 회원가입/로그인
→ 조건 입력
→ AI 입력값 구조화
→ 입력값 확인/수정
→ 시뮬레이션 실행 및 서버 DB 저장
→ 결과 대시보드
→ AI 전략 카드 생성 및 서버 DB 저장
→ 결과 이력 조회 가능
→ 전략 선택
→ 재계산
```

## 3. 공통 UI 원칙
- 로그인하지 않은 사용자는 조건 입력 이후 저장 기능을 사용할 수 없습니다.
- 모든 사용자별 데이터는 서버 DB에 저장됩니다.
- 숫자는 원화 단위와 만원 단위를 혼용하지 않습니다.
- AI 문구는 확정 표현을 피합니다.
- 모든 결과 화면에는 “입력값 기반 시뮬레이션” 안내를 표시합니다.

## 5. Front-end 금지 사항
- Front-end에서 `/internal/ai/*`를 직접 호출하지 않는다.
- Front-end에 AI API Key 또는 AI 서버 내부 URL을 노출하지 않는다.
- Front-end에서 사용자별 DB 저장 로직을 직접 처리하지 않는다.
- Front-end는 `packages/shared-contracts` 타입에 맞춰 요청/응답을 처리한다.
## 6. 화면별 API 상호작용 변경
```plain text
UI-04 조건 입력 화면
  → POST /api/ai/parse-input
  → Back-end가 /internal/ai/parse-input 호출
  → 구조화 결과 반환

UI-06 결과 대시보드
  → POST /api/simulation/golden-cross
  → Back-end가 계산 후 simulations 저장

UI-07 AI 전략 카드 화면
  → POST /api/ai/strategy-card
  → Back-end가 simulation 소유권 확인
  → Back-end가 /internal/ai/strategy-card 호출
  → Back-end가 strategy_cards 저장
  → Front-end에 카드 표시
```
