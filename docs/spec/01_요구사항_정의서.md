## 5. MVP 범위
### 포함
- 회원가입/로그인/로그아웃
- 사용자별 서버 DB 저장
- 자연어/수동 조건 입력
- 서울 자치구 가격 데이터
- 매수 D-Day 계산
- 스트레스 테스트
- 정책대출 적격성 간단 판정
- AI 전략 카드
- 결과 대시보드
- GitHub Actions 기반 CI 검증
### 제외/후순위
- 실제 대출 신청 연동
- 매물 추천/중개 기능
- 고도화된 소셜 로그인 전체 연동
- 법률/세무 수준의 정밀 조언
